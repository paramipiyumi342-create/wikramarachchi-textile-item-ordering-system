# Wikramarachchi Textile Item Ordering System

A desktop-based database management system developed using **Microsoft Access** to manage the item ordering process of **Wikramarachchi Textile**.

## 📋 Features

- User authentication (Login form)
- Customer management
- Item management
- Order management
- Payment management
- Automated total amount calculations using queries
- Reports for Customers, Orders, and Payments
- Add, Save, Delete, Next, and Search functionality

## 🛠️ Tools Used

- **Microsoft Access** – Database and forms
- **SQL** – Queries
- **VBA** – Automation (if used)
